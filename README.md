# Real Estate API

A Real Estate Management API built using Node.js, Express.js and MongoDB.

## Features

- User Authentication
- Property Management
- Customer Management
- Booking Management
- Payment Management

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- CORS

## Project Structure

Real-Estate-API/

- controller/
- middleware/
- models/
- routes/
- .gitignore
- package.json
- server.js

## Installation

Clone the repository:

git clone https://github.com/kamransari84/Real-Estate-API.git

Install dependencies:

npm install

## Run the Project

```bash
node server.js
